Favicon · Final

Castle + American Flag

Two-tower castle (one with garage door, one with windows) under an American flag — pays off the company name, the product, and the family-owned-since-1981 heritage in a single icon.

Saved at 6 sizes so every surface gets a crisp render: 16 / 32 / 48 tab + bookmark, 64 Windows tiles, 180 Apple touch icon, 512 Android home-screen.

Honest note: the flag and the horizontal window slats won't fully read at 16 px — they'll soft-blur into the silhouette. That's normal and actually a good thing; the eye fills in the brand from the overall shape. For the very smallest size we also save a simplified SVG (favicon.svg) that keeps the silhouette but drops the finest detail.

How to install

Add this block to the <head> of every page (Claude Code can do a sitewide find-and-replace). All seven files live at the repo root under /assets/.
