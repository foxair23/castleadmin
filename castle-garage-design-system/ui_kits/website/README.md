# Castle Garage Website — UI Kit

A pixel-faithful recreation of the Castle Garage Doors & Gates marketing site, factored into reusable React components.

## Files
- `index.html` — runnable demo: header → hero → trust strip → services → why → testimonials → CTA banner → footer.
- `Header.jsx` — fixed top nav, logo, dropdown menus, phone CTA.
- `Hero.jsx` — dark hero with photo background, eyebrow, red-amp headline, button row, trust items.
- `TrustStrip.jsx` — under-hero credentials row.
- `ServicesSection.jsx` — eyebrow + headline + 3-up service cards (icon tile, title, copy, red arrow link).
- `WhyCastle.jsx` — 4-up "Why Castle" feature row on white.
- `Testimonials.jsx` — 3-up testimonial cards with red left-border.
- `CTABanner.jsx` — full-bleed red call to action.
- `Footer.jsx` — dark footer with about, services, areas, contact columns.

## Usage
Open `index.html` in a browser. All visual values come from `colors_and_type.css` + the Castle stylesheet imported at the top of the file.
